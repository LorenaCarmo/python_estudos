## 📂 Organização do repositório

Os arquivos estão organizados de acordo com os exercícios desenvolvidos durante o curso, facilitando a consulta e o acompanhamento da evolução dos estudos.

## 🚀 Como executar os exercícios

1. Clone o repositório:

   ```bash
   git clone python_estudos
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd python_estudos
   ```

3. Execute o arquivo Python desejado:

   ```bash
   python python_estudos.py
   ```

*Observação: substitua `URL_DO_REPOSITORIO` pela URL do repositório no GitHub e `nome_do_arquivo.py` pelo arquivo que deseja executar.*
